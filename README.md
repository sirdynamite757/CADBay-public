# CADBay Public

Public-facing CADBay pages and browser-safe shared frontend code.

Included content is limited to public HTML, CSS, browser JavaScript, and advertisement presentation code. Credentials, account databases, server controls, native binaries, logs, and private configuration are intentionally excluded.

## Repository boundaries

- Public pages and fragments
- Shared browser behavior and API URL resolution
- Public styling and ad presentation code

The designer and engineer repositories contain development and native implementation work.
